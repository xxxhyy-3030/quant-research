# 跨市场联动与波动传导研究

这个项目主要分析 2016-2024 年中国股市、债市、汇市和货币政策变量之间的关系。使用的变量包括上证综指、10 年期国债收益率、人民币兑美元汇率、法定存款准备金率和 1 年期 MLF 利率。

项目重点不是做交易策略，而是用时间序列方法观察不同市场之间是否存在长期联动，以及政策变量冲击后，市场变量会如何反应。

## 研究问题

我主要关注三个问题：

1. 股市、债市、汇市和货币政策变量之间是否存在长期关系；
2. RRR、MLF 等政策变量变化后，对股市、债市和汇率是否有传导影响；
3. 部分变量是否存在波动聚集，能否用 GARCH 模型刻画。

## 数据与变量

数据整理为月度频率，主要变量如下：

| 变量 | 含义 |
| --- | --- |
| `ln_close` | 上证综指收盘价取对数 |
| `bond_yield` | 10 年期国债收益率 |
| `ln_exchange` | 人民币兑美元汇率取对数 |
| `rrr_rate` | 法定存款准备金率 |
| `mlf_rate` | 1 年期 MLF 利率 |

目前 notebook 中仍使用本地数据路径。正式展示前，最好把数据放到项目目录下，并改成相对路径。

## 方法

项目流程大致如下：

1. 清洗并合并月度数据；
2. 对指数和汇率取对数；
3. 使用 ADF 检验判断变量平稳性；
4. 使用 VAR 选择滞后阶数，并做 Johansen 协整检验；
5. 建立 VECM 模型，分析长期关系和短期调整；
6. 使用 IRF 和 FEVD 观察冲击传导；
7. 对 RRR 差分序列建立 GARCH 模型；
8. 通过调整模型设定和样本区间做稳健性检验。

## 主要结论

从样本结果看，货币政策变量、债券收益率、汇率和上证综指之间存在一定长期联动。这个结果更适合理解为样本期内的统计关系，而不是严格因果关系。

脉冲响应结果显示，政策变量冲击后，股市和债市会出现一定反应，但反应路径并不总是单调的。这说明政策影响可能会通过流动性、市场预期和风险偏好等渠道逐步传导。

方差分解结果显示，短期内各变量主要还是受自身冲击影响；随着预测期拉长，其他变量的解释比例有所上升，说明跨市场联动确实存在，但不是唯一主导因素。

GARCH 部分显示，RRR 变化存在一定波动聚集和厚尾特征。不过，由于 RRR 是政策变量，调整频率较低，这一部分更适合作为政策不确定性的刻画，而不是市场波动率模型。

## 局限性

这个项目还有几个明显不足：

1. 目前不是完整量化策略，没有信号构造、回测、交易成本和样本外检验；
2. “波动溢出”这一主题还可以加强，后续可以加入 DCC-GARCH 或 Diebold-Yilmaz 方法；
3. GARCH 只做了 RRR，若要更贴近量化金融，可以继续对股指收益率、债券收益率变化和汇率收益率建模；
4. VECM 的协整秩选择需要进一步解释清楚；
5. 数据路径和环境配置还需要整理，方便别人复现。

## 项目定位

这个项目更适合作为量化金融作品集里的时间序列或宏观金融计量项目，用来展示数据处理、金融变量建模和结果解释能力。

如果用于申请量化研究或量化交易岗位，它可以作为辅助项目。主打项目最好再配一个包含信号构造、回测和组合评估的策略项目。
