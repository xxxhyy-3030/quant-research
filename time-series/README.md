# 时间序列研究

本目录包含两个时间序列方向项目：跨市场波动溢出研究和上证指数预测。

## Notebook

- `cross-market-volatility-spillover.ipynb`
- `stock-prediction.ipynb`

## 跨市场波动溢出研究

该 Notebook 研究股票市场、债券市场、汇率市场和货币政策变量之间的联动关系。

主要内容包括：

- 数据预处理和描述性统计；
- ADF 平稳性检验；
- ARCH 效应检验；
- VECM 模型估计；
- 协整关系分析；
- 模型诊断；
- 脉冲响应分析；
- 方差分解；
- GARCH 模型估计和诊断；
- 稳健性检验。

## 上证指数预测

该 Notebook 使用 ARIMA/SARIMA 方法对上证指数进行建模和预测。

主要内容包括：

- 训练集和测试集划分；
- 平稳性诊断；
- 模型阶数选择；
- 残差诊断；
- 样本外预测评估；
- 滚动 ARIMA 收益率预测；
- 简单择时回测。

## 展示能力

- 计量时间序列建模；
- 预测效果评估；
- VECM、GARCH、ARIMA/SARIMA；
- 模型诊断和稳健性检验。

## 数据说明

原始宏观金融变量和指数数据未包含在仓库中。
