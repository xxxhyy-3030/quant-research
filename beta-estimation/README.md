# Beta 估计研究

## 项目概述

本项目围绕 CAPM Beta 估计展开，使用回归模型和滚动窗口方法度量股票相对于市场的风险暴露，并进一步扩展到行业层面和横截面分位数组合分析。

## Notebook

- `beta-estimation.ipynb`

## 主要内容

- 基准 CAPM 回归；
- 滚动月度 Beta 估计；
- 个股样例展示；
- 全样本月度 Beta 计算；
- 行业层面 Beta 分布；
- 横截面 Beta 分位数分析。

## 展示能力

- 使用 statsmodels 进行时间序列回归；
- 构建滚动估计流程；
- 度量风险因子暴露；
- 对 Beta 进行行业和横截面分组分析；
- 使用可视化展示 Beta 分布特征。

## 数据说明

原始收益率和市场因子数据未包含在仓库中。重新运行前需要替换本地数据路径。
