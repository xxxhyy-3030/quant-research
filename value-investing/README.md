# Steve Loughran 价值选股策略复现

## 项目概述

本项目复现并扩展 Steve Loughran 价值选股策略在 A 股市场的表现，将研报中的价值选股规则转化为完整的数据清洗、股票筛选、组合回测和可视化流程。

## Notebook

- `steve-loughran-value-screening.ipynb`

## 策略逻辑

策略从估值、分红和财务稳健性三个维度筛选股票：

- PB 低于市场平均水平；
- 使用五年平均盈利计算的 PE 低于市场平均水平；
- 每股流动资产相对于股价较高；
- 股息收益率不低于市场平均水平；
- 市现率低于市场平均水平；
- 长期借款占总资本比例低于 50%；
- 流动比率高于市场平均水平。

## 回测设计

- 月度信号生成；
- 等权组合构建；
- 日度收益回测；
- 根据调仓权重变化扣除千分之 1.3 的交易成本；
- 与上证指数进行基准比较。

## 核心输出

项目输出文件位于 `outputs/steve_loughran_value_screening/`：

- 净值曲线；
- 累计超额收益曲线；
- 持股数量变化；
- 最新一期持仓行业分布；
- 最新一期持仓市值分布；
- 绩效指标汇总表。

## 复现结果说明

本项目在年化收益率、Beta、最大回撤、胜率和盈亏比等指标上与原研报较为接近。交易日数量、持股数量分布和年化超额收益仍存在差异，可能来自数据可得性、退市股覆盖、财报滞后假设、调仓日定义、基准构造和超额收益计算口径不同。

## 数据说明

原始财务数据、行情数据、指数数据、行业分类数据和研报 PDF 未包含在仓库中，原因是这些文件可能受到数据库授权或版权限制。
