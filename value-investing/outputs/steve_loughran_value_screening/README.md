# Steve Loughran 价值选股策略输出文件

本目录保存 `value-investing` 项目的作品集展示材料，包括图表、指标表和 HTML 摘要页。

## 图表

- `figures/01_net_value_curve.png`：策略净值与基准净值对比。
- `figures/02_cumulative_excess_return.png`：累计超额收益曲线。
- `figures/03_holding_count_over_time.png`：持股数量随时间变化。
- `figures/04_latest_industry_distribution.png`：回测期末最新持仓行业分布。
- `figures/05_latest_market_cap_distribution_pie.png`：回测期末最新持仓市值分布。

## 表格

- `tables/daily_return_summary.csv`：收益指标。
- `tables/daily_risk_summary.csv`：风险指标。
- `tables/daily_profit_loss_summary.csv`：盈亏统计。
- `tables/daily_holding_count_summary.csv`：持股数量统计。
- `tables/industry_distribution.csv`：行业分布。
- `tables/market_cap_distribution.csv`：市值分布。

## HTML 摘要

- `portfolio_summary.html`：汇总展示关键图表和指标表，适合快速浏览项目结果。
